LibraryOS is a premium, state-of-the-art Library Management System (LMS) designed for schools, universities,
and reading hubs. Built on top of Django 4.2+, the platform provides user dashboards, borrow request flows,
search directories, and comprehensive admin settings. The entire user interface was updated to a modern
indigo-themed design layout incorporating a collapsible persistent sidebar navigation, breadcrumbs, responsive
cards, glassmorphic headers, and toast-based micro-interactions.
